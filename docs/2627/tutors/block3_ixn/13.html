RQ: Do differences in performance on explicit vs. implicit memory tasks differ for people experiencing different cognitive impairments?

Data dictionary:

variable description
Diagnosis Diagnosis classifies the three types of individuals: 1 = Amnesic patients, 2 = Huntingtons patients, and 3 = Control group of individuals with no known neurological disorder
Task Task tells us to which one of two tasks each study participant was randomly assigned to: 1 = Grammar (which consists of classifying letter sequences as either following or not following grammatical rules), and 2 = Recognition (which consists of recognising particular stimuli as stimuli that have previously been presented during the task)
Y Score
NoteMore detail about this dataset

The researchers designed a study yielding a 3 by 2 factorial design to test the above theory.

The tasks chosen by the researchers have been picked to map onto the theoretical differences between the three types of research participants. The first task (grammar) is known to reflect implicit memory processes, whereas the recognition task is known to reflect explicit memory processes. If the theory is correct, we would expect the difference in scores between the recognition and grammar tasks to be relatively similar for the control and amnesiac groups, but relatively larger for the Huntingtons group compared to controls.

Keep in mind that each person has been randomly assigned to one of the two tasks, so there are five observations per cell of the design.

The data in cognitive_experiment_3_by_2.csv contain three attributes collected from \(n=30\) participants.

Anticipate the model coefficients

Question 4

What does Diagnosis = 0 represent? What about Task = 0?

Solution

Solution 4.

  • Diagnosis = 0 represents the reference level of Diagnosis, namely Control.
  • Task = 0 represents the reference level of Task, namely Recognition.

Question 5

How many dummy variables will it take to represent Diagnosis? How about Task?

Further, if we model an interaction between Diagnosis and Task, how many interaction terms will our model contain?

🗂️ See Categorical/categorical example > How many interaction terms flash card.

Solution

Solution 5. Diagnosis will require two dummy variables: one comparing Amnesia to Control, and the other comparing Huntingtons to Control.

Task only requires a single variable, which will compare Grammar to Recognition.

For calculating the number of interaction terms: This is a 3x2 design, so \(r\) = 3 and \(c\) = 2, so:

\[ \begin{align} & (r - 1) \times (c - 1)\\ =~& (3 - 1) \times (2 - 1) \\ =~& 2 \times 1 \\ =~& 2 \end{align} \]

Our model will contain two interaction terms.

Question 6

Write the mathematical model expression for the model we’ll fit, which in R syntax is Score ~ Diagnosis * Task.

🗂️ See Categorical/categorical example > Mathematical model specification flash card.

Solution

Solution 6. \[ \begin{align} \text{Score} ~=~& \beta_0 + (\beta_1 \cdot \text{Diagnosis}_\text{Amnesia}) + (\beta_2 \cdot \text{Diagnosis}_\text{Huntingtons}) + (\beta_3 \cdot \text{Task}_\text{Grammar}) + \\ & (\beta_4 \cdot \text{Diagnosis}_\text{Amnesia} \cdot \text{Task}_\text{Grammar}) + (\beta_5 \cdot \text{Diagnosis}_\text{Huntingtons} \cdot \text{Task}_\text{Grammar}) + \epsilon \\ \end{align} \]

Write:

$$
\begin{align}
\text{Score} ~=~& \beta_0 + 
(\beta_1 \cdot \text{Diagnosis}_\text{Amnesia}) + 
(\beta_2 \cdot \text{Diagnosis}_\text{Huntingtons}) + 
(\beta_3 \cdot \text{Task}_\text{Grammar}) +  \\
& (\beta_4 \cdot \text{Diagnosis}_\text{Amnesia} \cdot \text{Task}_\text{Grammar}) + 
 (\beta_5 \cdot \text{Diagnosis}_\text{Huntingtons} \cdot \text{Task}_\text{Grammar}) + 
\epsilon \\
\end{align}
$$


Note: The following model is not correct, because it doesn’t contain dummy variables for Diagnosis:

\[ \text{Score} = \beta_0 + (\beta_1 \cdot \text{Diagnosis}) + (\beta_2 \cdot \text{Task}) + (\beta_3 \cdot \text{Diagnosis} \cdot \text{Task}) + \epsilon \]

Question 7

The model will have six coefficients in total.

Based on the zero points you identified for each predictor in Q4 and the model formula you worked out in Q6, write one sentence for each coefficient that describes what it will mean.

🗂️ See Categorical/categorical example > Interpret results flash card.

Solution

Solution 7.

  • \(\beta_0\) = (Intercept)
    • The estimated mean score for control participants on the recognition task.
  • \(\beta_1\) = DiagnosisAmnesia
    • On the recognition task, how does the score increase/decrease when moving from control participants to amnesia participants?
  • \(\beta_2\) = DiagnosisHuntingtons
    • On the recognition task, how does the score increase/decrease when moving from control participants to Huntingtons participants?
  • \(\beta_3\) = TaskGrammar
    • For control participants, how does the score increase/decrease when moving from the recognition task to the grammar task?
  • \(\beta_4\) = DiagnosisAmnesia:TaskGrammar
    • How does moving from the recognition task to the grammar task increase/decrease the difference between control participants and amnesia participants?
    • Or: How does moving from control participants to amnesia participants increase/decrease the difference between the recognition task and the grammar task?
  • \(\beta_5\) = DiagnosisHuntingtons:TaskGrammar
    • How does moving from the recognition task to the grammar task increase/decrease the difference between control participants and Huntingtons participants?
    • Or: How does moving from control participants to Huntingtons participants increase/decrease the difference between the recognition task and the grammar task?

Fit and interpret model

Question 8

Fit the model defined in Q6, and name the output cog_mdl.

🗂️ See Categorical/categorical example > Fit the model flash card.

Solution

Solution 8. 

cog_mdl <- lm(Score ~ Diagnosis * Task, data = cog_data)
